
# ENEM Score Modeling and Item Response Analysis

This repository contains an end-to-end data science project focused on modeling, analyzing, and extracting patterns from the microdata of the Brazilian National High School Exam (**ENEM - Exame Nacional do Ensino Médio**). The project encompasses advanced Exploratory Data Analysis (EDA), dimensionality reduction for feature extraction, and high-performance predictive modeling.

## About ENEM (Context for International Recruiters)
The **ENEM** is Brazil's national standardized high school exam and serves as the primary gateway to higher education across the country. With millions of applicants annually, it stands as one of the largest academic examinations in the world. The exam consists of hundreds of multiple-choice questions spread across four core knowledge areas, alongside an essay. Because it employs a complex psychometric scoring methodology known as Item Response Theory (IRT), analyzing its dataset presents a highly sophisticated data challenge involving large-scale behavioral matrix parsing, dense socio-economic variables, and non-linear performance evaluation.

## Project Overview

The primary goal of this project is to model applicant performance across multiple knowledge areas on the ENEM exam and investigate the relationship between raw success rates (percentage of correct answers) and the official scores calculated using **Item Response Theory (TRI)**. Additionally, the project uses unsupervised learning techniques to extract latent cognitive components from participant response matrices and applies supervised learning to predict score thresholds.

## Core Features & Workflow

### 1. Data Merging & Feature Engineering
* **Data Synthesis:** Merged raw administrative datasets with participant response matrices (`TX_RESPOSTAS_*`) to correlate contextual metadata with academic output.
* **Success Metric Construction:** Developed custom pipelines to parse raw text response strings and match them against official templates (`TX_GABARITO_*`), calculating accurate percentages of correct answers per subject block (Natural Sciences, Human Sciences, Languages, and Mathematics).

### 2. Exploratory Data Analysis & TRI Assessment
* Investigated the non-linear distributions generated by the official Item Response Theory (TRI) grading mechanism.
* Formulated correlation matrices comparing official weighted scores with direct hit rates to evaluate grading variances.
* Quantified differences and deviations between estimated linear metrics and true TRI parameters using visual distribution analysis.

### 3. Latent Structure Extraction (NMF)
* Applied **Non-Negative Matrix Factorization (NMF)** to large-scale, sparse individual answer sets.
* Decomposed response patterns into distinct latent factors to reveal hidden clusters of subject proficiency, question difficulty groups, and applicant cognitive profiles.

### 4. Predictive Modeling
* **Algorithm Deployment:** Implemented extreme gradient boosting via **XGBoost** to map structural socio-economic indicators and answer frequencies directly to final performance bands.
* **Validation Strategy:** Utilized a robust **K-Fold Cross-Validation** approach combined with local search optimization (`scipy.optimize.basinhopping`) to minimize mean squared errors and prevent overfitting.
* **Evaluation:** Scored models using **$R^2$ Score**, **Mean Squared Error (MSE)**, and **Pearson Correlation Coefficients** to validate predictive strength against actual official metrics.

## Technologies & Frameworks

* **Data Manipulation & Processing:** `pandas`, `numpy`, `pyarrow` (Parquet parsing)
* **Machine Learning & Optimization:** `scikit-learn` (NMF, KFold), `XGBoost`, `scipy` (Basinhopping optimization)
* **Data Visualization:** `matplotlib`, `seaborn`, `plotly` (interactive dashboards and distribution modeling)

## Key Insights & Structural Findings

* **TRI vs. Raw Percentage:** The EDA successfully demonstrated that identical percentages of correct answers map to varying final scores, validating how TRI weights question difficulty over absolute volume of correct choices.
* **Socio-Economic Signatures:** The XGBoost model confirmed that regional parameters, administrative school types (`TP_DEPENDENCIA_ADM_ESC`), and specific questionnaire elements share a high predictive weight on mathematical performance.
* **Dimensionality Reduction:** The NMF implementation successfully distilled hundreds of raw answer columns into orthogonal cognitive dimensions, simplifying multi-collinear inputs for final grading optimization.
